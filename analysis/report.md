## 6. 규칙 replay (재현 가능한 범위)

로그에서 이름·학번·생년월일은 제거됐으므로 '필수 항목 누락' 과 '형식 위반' 은 재현 불가. 재현 가능한 규칙: (a) 대학명 == '세종대학교' 정확 일치, (b) confidence ≥ 0.85, (c) REJECTED & conf ≥ 0.9 → NEEDS_REVIEW.

- (a) AUTO_APPROVED 인데 대학명이 '세종대학교' 아님: **0건**
- (b) AUTO_APPROVED 인데 confidence < 0.85: **0건**
- (c) LLM REJECTED & conf ≥ 0.9 인데 NEEDS_REVIEW 태그 없음: **5건**
  - 태그 없는 건은 모두 2026-09-24 이전, 태그 있는 건은 모두 2026-09-27 이후 → 규칙이 시즌 중간에 배포된 것으로 보인다. 배포 전 건은 규칙 평가에서 제외하거나 배포일을 기준으로 나눠 봐야 한다.
- 에브리타임 경로에 도구 호출이 남은 6건은 모두 2026-09-24 이전 → 같은 배포 경계로 추정.
- 추출된 대학명 값 분포: {'세종대학교': 306, 'NULL': 34, '세종대': 3}
  - '세종대'(축약형) 3건의 최종 status: {'RETRY_REQUESTED': 3} → 정확 일치 규칙 때문에 축약형은 자동승인에서 탈락한다. 에브리타임 화면은 '세종대'로 표기되므로 프롬프트가 정규화를 떠안고 있는 상태.

## 8. 요약 — 이 로그가 말해주는 것

1. 확신도 임계치(0.85)는 이 시즌 데이터에서 아무것도 가르지 않았다. 자동승인 건은 전부 0.95 이상이고, 0.85 미만 건은 애초에 LLM 이 AUTO_APPROVED 를 내지 않았다. 임계치를 바꿔 자동승인율을 올리는 길은 없다.
2. 재촬영 78건의 원인은 '모델이 못 읽음'이 아니라 '화면에 정보가 없음'이거나 '프롬프트 기준이 화면과 안 맞음'이다 — QR 경로는 생년월일 미표시(29건), 에브리타임 경로는 화면에 없는 8자리 학번 요구(9건), 'XX학번·재학생' 표기를 입학년도로 미인정(11건), 화면의 '세종대'를 대학명으로 미인정(9건). 에브리타임 쪽 세 가지는 전부 프롬프트 수정만으로 없앨 수 있다.
3. 에브리타임 경로가 QR 경로보다 자동승인율이 10%p 낮고 거절율은 6배다. 대학명 '세종대'(축약) 정규화와 입학년도 기준을 프롬프트/게이트에 명시하면 가장 싸게 개선된다.
4. 운영자가 승인한 13건 중 9건은 LLM 이 스스로 NEEDS_REVIEW 를 낸 건(확신도 0.72~0.85, 그중 1건은 API 오류 폴백), 4건은 REJECTED→NEEDS_REVIEW 강등 규칙이 구한 건이다. 이 규칙이 없었으면 4명이 부당 거절당했다.
5. 학과 목록에 오타·장난 값 15개가 들어가 있고 search_department 가 그걸 그대로 다음 판정에 노출한다. 데이터 품질 이슈가 모델 이슈보다 먼저다.
6. 검증 한계: 운영자 판정이 16건뿐이라 '오승인' 추정이 불가능하다. 자동승인 252건 중 무작위 30건을 사람이 다시 보는 표본 검수가 있어야 정확도를 말할 수 있다.
