# 운영 종료 후 데이터 분석

2026 가을 시즌 운영 데이터로 포트폴리오·회고에 쓴 지표를 재현하는 SQL과 스크립트.

## 구성

| 경로 | 내용 |
|---|---|
| `sql/01~08_*.sql` | Supabase SQL Editor에서 실행하는 집계 쿼리. 각 파일 상단에 목적과 민감 정보 처리 원칙 명시 |
| `analyze.py` | `data/*.csv`를 읽어 `output/*.png` 생성 + 요약 지표 출력 |
| `output/*.png` | 집계값·분포만 담은 그래프 (공유 가능) |
| `data/` | **커밋하지 않음** (`.gitignore`). raw 집계 CSV라도 user_id 등이 섞일 수 있어 로컬 전용 |
| `student_verifications.csv` | 익명화한 학생인증 로그 343건 (이름·학번·생년월일 제거, id 해시, 텍스트 내 개인정보 마스킹) |
| `evaluate_rules.py` → `report.md`, `eval_out/` | 규칙 평가 하네스: 게이트 개입 집계, 확신도 임계치 스윕, 재촬영 원인 분류, 경로별 비교, 규칙 replay |

## 실행

```bash
pip install -r analysis/requirements.txt
# sql/*.sql 실행 결과를 data/<번호>_<이름>.csv 로 저장 (매핑은 analyze.py 상단 docstring)
python analysis/analyze.py
```

## 학생인증 에이전트 지표 — 두 시점의 수치

같은 지표를 두 시점에서 집계했고 둘 다 포트폴리오에 쓴다. 분모가 다르므로 섞어 쓰지 않는다.

| 시점 | 인증 건수 | 자동승인 | 자동승인율 | LLM 호출 합계 | 건당 평균 호출 |
|---|---|---|---|---|---|
| 운영 중 관리자 통계 캡처 (`GET /api/admin/verification/stats`) | 340 | 247 | 72.6% | 553 | 1.63 |
| 운영 마지막 날 전체 로그 내보내기 (2026-10-02 00:30, `student_verifications.csv`) | 343 | 252 | 73.5% | 556 | 1.62 |
| 운영 종료 2일 후 DB 스냅샷 (`sql/04`) | 274 | 193 | 70.4% | — | 1.64 |

세 시점 사이에 인증 건수가 343건에서 274건으로 69건 줄어든 이유: `student_verifications.user_id`가 `ON DELETE CASCADE`라 회원 탈퇴 시 인증 기록이 함께 삭제된다. 활동이 많았던 유저일수록 시즌 종료 후 탈퇴 비율이 높았다. 그럼에도 건당 평균 LLM 호출(1.62~1.64)과 자동승인율(73.5% → 70.4%)이 거의 같아, 탈퇴로 빠진 기록이 특별히 다른 분포가 아니었음을 확인했다.

운영 지표 테이블을 탈퇴와 무관하게 보존하려면 `ON DELETE CASCADE` 대신 `user_id`를 nullable로 두고 `ON DELETE SET NULL`로 익명화했어야 했다. 다음 프로젝트의 교훈으로 기록한다.

종료 시점 스냅샷 기준 평균 처리시간은 7.35초(세종대 QR 경로 9.0초, 에브리타임 경로 4.1초)다. QR 경로가 느린 이유는 학번 중복 조회·학과 사전 조회 도구가 QR 경로에만 붙어 tool use 추가 턴이 생기기 때문이다 (경로별 평균 호출 1.93 vs 1.06). 에브리타임 경로는 화면에 8자리 학번이 없어 도구 없이 1턴으로 끝나는 대신, 학번 기반 중복 가입 방어가 적용되지 않는다 (이미지 해시 중복 차단만 적용).

세 번째 시점으로, 운영 중 내보낸 전체 로그 343건을 익명화해 `student_verifications.csv`로 커밋했고 `evaluate_rules.py`로 규칙 단위 평가를 돌렸다. 결과는 [`report.md`](report.md). (343건은 탈퇴 cascade 이전 시점이라 위 274건 스냅샷보다 많다.)

규칙 단위 평가(`evaluate_rules.py` → [`report.md`](report.md))는 탈퇴 전 전체 로그인 343건 CSV를 기준으로 한다. 포트폴리오의 73% / 18% / 5.1% / 3.8%도 이 시점 수치다.
